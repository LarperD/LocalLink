# [📢] What is it ? What does it do ? :
 - Turn your Devices into **Controllers** for pc gaming
 - Running Locally on Browsers
 - Fast input system
 - Comes with (useless) installer

> [!NOTE]
> The screen mirroring system wasn't make for real-use as the backend is too slow for gaming. // Disabling it will improve a lot of input latency (I only add it for visualization.)
<br/>

This is my very first **Vibe Coding** Project.
I'm a remote control hater cause' I just want to GAME !

**LocalLink** is **unlike SteamLink**. The purpose is to use your device as a "**Controller**" only.
### [🔰] Features :
- Audio Listener
- Mini Screen
- Mouse (Touchpad)
- Keyboard (Shortcut Maker, Live Typeing)
- Gamepad (Multi-Layout, LayoutEditor, Background Screen,Touch Background)
- PC (Input Passing) // PC to PC
### [🩵] Tested on :
- _**Linux** : Arch linux + SwayWM // **Pipewire**_
- _**Windows** : Tiny 10 22H2_
### [‼️] Firewalls :
- _Please allow `8765` by default for `tcp` port_
### [🎮] To Run it :
-  _`python launch.py`_
